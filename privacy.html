1. About this application

ModdyLazy-Ladybug ("the App") is a personal AI assistant used solely by its owner. It is not a commercial product and is not offered to the public.

2. Information the App accesses

With the user's explicit consent via Google OAuth, the App may access Google user data limited to the scopes granted on the consent screen (for example, basic profile information and data from Google services the user chooses to authorize). The App only requests the minimum access needed to perform the tasks requested by the user.

3. How the information is used

Google user data is used only to provide the App's features to the user, such as reading, organizing, or creating content on the user's behalf when the user asks the assistant to do so. The data is not used for advertising, profiling, or any purpose unrelated to these features.

4. Storage and security

OAuth tokens and any retrieved data are stored only on the owner's own devices or private infrastructure, and are protected using reasonable security measures. Client secrets and tokens are never published or committed to public code repositories.

5. Sharing

Google user data is not sold, rented, or shared with third parties, except where data is processed by the AI service the user has chosen to perform a requested task, or where required by law.

6. Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deleting data

You can revoke the App's access to your Google account at any time at myaccount.google.com/permissions. After access is revoked, stored tokens become invalid. You may also request deletion of any stored data by contacting the email below.
